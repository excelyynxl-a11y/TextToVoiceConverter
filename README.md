# 🗣️ Text to Voice Converter

A simple and interactive **Text to Speech** web app built using **HTML**, **CSS**, and **JavaScript**.  
Users can type or paste any text, select a voice, and listen to it instantly — powered by the browser’s **Speech Synthesis API**.

---

## 🚀 Features
- 📝 Type or paste any text in the text area  
- 🔊 Convert text to speech using built-in browser voices  
- 🎙️ Choose from multiple available voices  
- ⌨️ Press **Enter** to play instantly  

---

## 🛠️ Tech stack

- **HTML** – for structure  
- **CSS** – for styling and layout  
- **JavaScript** – for text-to-speech logic and event handling  
---

## 🤔 How it works?
- retievies text from textarea
- create new SpeechSynthesisUtterance 
- sets chosen voice 
- calls speechSynthesis.speak() to speak!
